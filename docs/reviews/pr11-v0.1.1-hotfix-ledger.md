## v0.2 carry-forward

**Pre-flight registry-health check before any write.** `ctx.modelRegistry.getError()` is registry-wide: a provider broken *anywhere else* in `models.json` (not just the one this write targets) makes every plugin write's post-write verification fail, ending in a confusing restore even though the plugin's own write was perfectly correct. A v0.2 refinement should check registry health *before* attempting a write and surface a clear, actionable message ("provider X elsewhere in models.json is broken — fix it before registering") rather than letting an unrelated pre-existing problem present as if this write failed.
